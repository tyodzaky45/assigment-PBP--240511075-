==================================================
        PERBANDINGAN PLATFORM APLIKASI
==================================================

1. BAHASA UTAMA
- Web     : HTML, CSS, JavaScript
- Desktop : C++, C#, Java, Swift
- Mobile  : Native: Kotlin (untuk Android) dan Swift (untuk iOS)

2. ARSITEKTUR
- Web     : Client-Server: Klien (browser) mengirimkan permintaan (request) ke server, dan server memproses serta mengembalikan data.
- Desktop : Menggunakan pola desain seperti MVC (Model-View-Controller) atau MVVM (Model-View-ViewModel) untuk memisahkan logika antarmuka dan data.
- Mobile  : Berbasis MVC, MVVM, atau Clean Architecture guna memastikan kode modular, mudah diuji, dan skalabel di layar perangkat yang beragam.

3. CARA DISTRIBUSI
- Web     : Diunggah (deployed) ke web server atau layanan cloud hosting (seperti AWS, Vercel, Netlify, atau Google Cloud).
- Desktop : Didistribusikan lewat toko aplikasi resmi (Microsoft Store, Mac App Store, Linux Package Manager) atau diunduh langsung dari situs web resmi pengembang.
- Mobile  : Melalui toko aplikasi resmi: Google Play Store (Android) dan Apple App Store (iOS).

4. KEUNGGULAN
- Web     : Aplikasi web dapat berjalan di berbagai sistem operasi dan perangkat tanpa pengembangan ulang.
- Desktop : Aplikasi desktop sering kali memiliki fitur yang lebih kaya dan kompleks dibandingkan dengan aplikasi mobile atau web.
- Mobile  : Aplikasi mobile dirancang untuk interaksi sentuhan yang lebih responsif.

5. KETERBATASAN
- Web     : Aplikasi web rentan terhadap serangan siber seperti SQL Injection dan Cross-Site Scripting (XSS).
- Desktop : Pembaruan perangkat lunak memerlukan instalasi manual oleh user, yang bisa jadi merepotkan.
- Mobile  : Aplikasi harus kompatibel dengan versi sistem operasi dan perangkat keras yang berbeda-beda.

6. CONTOH APLIKASI
- Web     : Google Drive, Canva (web)
- Desktop : Spotify Desktop, Microsoft Word
- Mobile  : WhatsApp, Facebook, X

==================================================
              BAGIAN 3 — REFLEKSI
==================================================

Platform yang paling menarik bagi saya untuk dipelajari adalah Mobile karena fleksibilitas dan aksesibilitasnya yang tinggi, mengingat aplikasi di perangkat genggam kini menjadi bagian tak terpisahkan dari aktivitas sehari-hari banyak orang. Pengembangan platform ini terasa sangat memuaskan, apalagi dengan adanya teknologi lintas platform seperti Flutter atau React Native yang membuat proses pembuatannya dinamis dan seru. Namun, perjalanan belajar ini tidak lepas dari tantangan, di mana hambatan terbesar muncul saat setup environment. Spesifikasi Android Studio yang berat, ukuran SDK yang besar, hingga kerumitan konfigurasi emulator dan konflik versi Java atau Gradle sering kali memicu galat yang lumayan membingungkan. Untuk mengatasi kendala tersebut, saya berencana membaca panduan resmi serta diskusi komunitas secara teliti sebelum menginstal dependensi, memanfaatkan perangkat HP fisik via USB debugging daripada emulator demi menghemat penggunaan RAM, serta mencatat setiap langkah konfigurasi versi agar proses penyelesaian masalah ke depannya bisa berjalan jauh lebih efektif.
